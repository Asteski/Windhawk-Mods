# windhawk-mods

My collection of Windhawk mods:

- [System Flyout Fixes](mods/asteski-system-flyout-fixes.wh.cpp) — Snipping Tool toolbar below a top taskbar and click-through system OSDs

- [Task View: Desktops on Top](mods/asteski-task-view-desktops-on-top.wh.cpp) — experimental Windows 11 layout with virtual desktops above the window overview
- [Edge UI Tweaks](mods/asteski-edge-ui-tweaks.wh.cpp) — menus, fonts, favorites, tabs, extension spacing, rounded corners and optional menu-shadow removal
- [Auto Dark Titlebar](https://github.com/Asteski/windhawk-mods/blob/main/mods/asteski-auto-dark-titlebar.wh.cpp)
- [Force App Window to Corner](https://github.com/Asteski/windhawk-mods/blob/main/mods/asteski-force-app-to-corner.wh.cpp)
- [Snap Commander](https://github.com/Asteski/windhawk-mods/blob/main/mods/asteski-snap-commander.wh.cpp) (available in Windhawk Store)
- [Start Button Actions](https://github.com/Asteski/windhawk-mods/blob/main/mods/asteski-start-button-actions.wh.cpp)
- [Toggle Hidden Files](https://github.com/Asteski/windhawk-mods/blob/main/mods/asteski-toggle-hidden-files.wh.cpp) (available in Windhawk Store)
- [Toggle Taskbar Visibility](https://github.com/Asteski/windhawk-mods/blob/main/mods/asteski-toggle-taskbar-visibility.wh.cpp)
